# Otwarte repozytoria AlgorOne

Rozpoczynamy proces otwierania źródeł komponentów platformy AlgorOne (https://www.algor.com.pl/algorone). 
Otwieramy kod w modelu podwójnej licencji: GPL-3.0 oraz komercyjnej. 

### 🤝 Współpraca i Umowa Licencyjna Autora (Contributor License Agreement - CLA)
Abyśmy mogli legalnie oferować wersje komercyjne, musimy posiadać pełne i nieograniczone prawa do relikencjonowania kodu. Warunki wspłóracy określone są w dokumencie `CONTRIBUTING.md` dla każdego repozytorium osobno.
